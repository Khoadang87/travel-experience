# travel-experience
Virtual travel experience: continuous 360° walks through real cities

## Cities
- [Hội An walk](cities/hoian/): real 360° footage (11 min, 2560×1280, one continuous HLS stream each way), joystick up = walk forward, down = walk back, drag with a finger to look anywhere, `?gyro=1` for tilt. Stopping freezes the footage. Credits in `cities/hoian/CREDITS.md`.
