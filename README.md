# travel-experience
Virtual travel experience: freely explorable 3D worlds of famous places.

The earlier real-footage 360° walks (Hội An, Longshan, Ximending) were retired on 2026-11-04; they remain in git history.

## Current prototype
- [Longshan courtyard 3D world](cities/taipei/test/world-ls.html) (three.js, credits in `cities/taipei/test/world/CREDITS.md`).

Serve the repo root with `python3 -m http.server 8000`. Test: `python3 tests/realuser_world_ls.py`.
